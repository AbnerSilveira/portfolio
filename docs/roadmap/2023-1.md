## Objetivo acadêmico

Demonstrar domínio dos conceitos de **aritmética modular**, **algoritmo de Euclides estendido** e **teorema de Euler** aplicados à criptografia assimétrica. Implementar RSA **do zero**, sem bibliotecas criptográficas.

## Objetivo do portfólio

Ferramenta didática interativa que visualiza cada etapa do RSA:

1. Geração de dois primos $p$ e $q$
2. Cálculo de $n = p \cdot q$
3. Cálculo de $\phi(n) = (p-1)(q-1)$
4. Escolha de $e$ coprimo com $\phi(n)$
5. Cálculo de $d$ via algoritmo de Euclides estendido
6. Encriptação: $c = m^e \mod n$
7. Decriptação: $m = c^d \mod n$

Usuário pode inserir mensagem, ver cada passo animado, mexer nos primos.

## Obstáculos esperados

### BigInt e React

React não serializa BigInt por padrão. Converter para string na renderização:

```typescript
const display = value.toString();
```

### Aleatoriedade cripto

Não usar `Math.random()` nunca. Usar `crypto.getRandomValues()` do Web Crypto API:

```typescript
function randomBigInt(bits: number): bigint {
  const bytes = Math.ceil(bits / 8);
  const buf = new Uint8Array(bytes);
  crypto.getRandomValues(buf);
  return buf.reduce((acc, b, i) => acc + (BigInt(b) << BigInt(i * 8)), 0n);
}
```

### Primos grandes são lentos

Miller-Rabin com muitas iterações em primos de 512 bits pode demorar 2-5 segundos no browser. Opções:

- Usar Web Worker para não travar UI
- Ou limitar a primos de 32-64 bits (didático, não seguro)

**Decisão:** para demo didática, ficar em 32 bits. Adicionar aviso "modo didático, não seguro para uso real".

### Animação de cálculos longos

Framer Motion em sequências longas pode ficar pesado. Alternativa: usar requestAnimationFrame puro com índice do passo atual.

```mdx
## Sobre o projeto

RSA é a base da criptografia assimétrica moderna. Entender como ele funciona — não só como usar uma biblioteca — é o diferencial entre saber "fazer bcrypt" e saber arquitetar sistemas criptográficos com confiança.

Este projeto implementa RSA do zero (sem `node:crypto`), expondo cada cálculo matemático de forma visual.

## Demo

[Abrir a demo interativa](/projetos/rsa-visualizer/demo)

A demo é servida no mesmo deploy do portfólio: `apps/projects/rsa-visualizer` é um package de componentes consumido pela rota `/projetos/rsa-visualizer/demo` em `apps/web`. Sem iframe, sem subdomínio, sem variável de URL externa.

## Conceitos cobertos

- Aritmética modular e teorema de Euler
- Algoritmo de Euclides estendido para encontrar o inverso modular
- Teste de primalidade Miller-Rabin (vs Fermat, que falha em Carmichael numbers)
- Exponenciação modular por quadrados e multiplicações

## Destaques técnicos

- Motor RSA com 95%+ de cobertura de testes
- Uso de BigInt nativo do JavaScript (sem biblioteca externa)
- Web Workers para não travar a UI em cálculos pesados
- Animação passo a passo com Framer Motion

## Limitações acadêmicas

Usa chaves de 32 bits para permitir visualização em tempo real. Em produção, RSA usa 2048+ bits (e, na prática, é substituído por algoritmos mais modernos como ECDSA/Ed25519 em novos sistemas).
```
